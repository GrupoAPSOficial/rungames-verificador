# Run Games – Verificador de hardware

Downloads do verificador do [Run Games](https://rungames.com.br): um programa para Windows 10 e 11, sem instalação, que lê as peças do PC (processador, placa de vídeo, memória, discos, versão do Windows e resolução) para mostrar quais jogos rodam nele.

- Não lê nome do PC, usuário, arquivos, senhas nem números de série.
- Não pede permissão de administrador.

Baixe a versão mais recente em [Releases](https://github.com/GrupoAPSOficial/rungames-verificador/releases/latest).
